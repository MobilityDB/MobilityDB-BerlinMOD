# BerlinMOD on the base map of Hanoi

This directory prepares the base map of **Hanoi (Vietnam)** from OpenStreetMap
for the BerlinMOD generator of this repository. Only the preparation depends
on the city: the road network is loaded with the `mapconfig.xml` of
`BerlinMOD/`, and the trips are generated by `BerlinMOD/berlinmod_datagenerator.sql`,
as for Brussels. `hanoi_preparedata.sql` fills the home and work regions with
the population and the number of enterprises of the 30 districts of Hanoi, and
`export_geojson.sql` exports the trips and the districts as GeoJSON for
[Kepler.gl](https://kepler.gl/). The trips can also be shown in QGIS with the
[MOVE plugin](https://github.com/MobilityDB/move).

## 1. The OSM map of Hanoi

Download the OpenStreetMap data of Hanoi within the bounding box below:

```bash
CITY="hanoi"
BBOX="105.28,20.56,106.07,21.384"
wget -O "${CITY}.osm" "http://www.overpass-api.de/api/xapi?*[bbox=${BBOX}][@meta]"
```

Create the database `hanoi` with the extensions it needs, from the root of this
repository:

```bash
createdb -h localhost -p 5432 -U dbowner hanoi
# replace localhost with your database host, 5432 with your port,
# and dbowner with your database user
psql -h localhost -p 5432 -U dbowner -d hanoi -c 'CREATE EXTENSION hstore'
# adds the hstore extension needed by osm2pgsql
psql -h localhost -p 5432 -U dbowner -d hanoi -c 'CREATE EXTENSION MobilityDB CASCADE'
# adds the PostGIS and the MobilityDB extensions to the database
psql -h localhost -p 5432 -U dbowner -d hanoi -c 'CREATE EXTENSION pgRouting'
# adds the pgRouting extension
```

Load the map and convert it into a routable network with the road types that
`BerlinMOD/mapconfig.xml` selects:

```bash
osm2pgrouting -h localhost -p 5432 -U dbowner -W passwd -f hanoi.osm --dbname hanoi \
  -c BerlinMOD/mapconfig.xml
```

## 2. Generating the data of Hanoi

Load all the layers of the OSM file, including the administrative regions, and
prepare the home and work regions with the statistics of every district:

```bash
osm2pgsql -c -H localhost -P 5432 -U dbowner -W -d hanoi hanoi.osm
psql -h localhost -p 5432 -U dbowner -d hanoi -f BerlinMOD/hanoi/hanoi_preparedata.sql
# samples home and work nodes, transforms the data to SRID 3857
```

Then run the generator of BerlinMOD at the scale factor wanted:

```bash
psql -h localhost -p 5432 -U dbowner -d hanoi -f BerlinMOD/berlinmod_datagenerator.sql
psql -h localhost -p 5432 -U dbowner -d hanoi \
  -c 'SELECT berlinmod_generate(scaleFactor := 0.005)'
```

## 3. Exporting GeoJSON for Kepler.gl

`export_geojson.sql` creates two functions, which write the trips of a day and
the districts into a directory of the database server:

```bash
psql -h localhost -p 5432 -U dbowner -d hanoi -f BerlinMOD/hanoi/export_geojson.sql
psql -h localhost -p 5432 -U dbowner -d hanoi \
  -c "SELECT export_trips('/tmp/', '2020-06-01')"
# writes trips_2020-06-01.geojson
psql -h localhost -p 5432 -U dbowner -d hanoi \
  -c "SELECT export_municipalities('/tmp/')"
# writes municipalities.geojson
```
