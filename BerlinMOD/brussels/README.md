# BerlinMOD on the base map of Brussels

This directory prepares the base map of **Brussels (Belgium)** from OpenStreetMap
for the BerlinMOD generator of this repository, the default base map of the
benchmark. Only the preparation depends on the city: the road network is loaded
with the `mapconfig.xml` of `BerlinMOD/`, and the trips are generated by
`BerlinMOD/berlinmod_datagenerator.sql`, as for Hanoi. `brussels_preparedata.sql`
fills the home and work regions with the population on January 1, 2017 and the
number of enterprises on December 31, 2018 of the 19 municipalities of the
Brussels-Capital Region, from the
[list of its municipalities](https://en.wikipedia.org/wiki/List_of_municipalities_of_the_Brussels-Capital_Region)
and the [economic statistics of IBSA](http://ibsa.brussels/themes/economie),
which `brussels.xlsx` gathers. `brussels_creategraph.sql` builds the road network
with SQL instead of osm2pgrouting, for data that does not come from OSM, and can
contract the graph.

## 1. The OSM map of Brussels

Download the OpenStreetMap data of Brussels within the bounding box below:

```bash
CITY="brussels"
BBOX="4.22,50.75,4.5,50.92"
wget -O "${CITY}.osm" "http://www.overpass-api.de/api/xapi?*[bbox=${BBOX}][@meta]"
```

or take the extract that the documentation of the generator uses,
[brussels_osm.zip](https://docs.mobilitydb.com/data/brussels_osm.zip).

Create the database `brussels` with the extensions it needs, from the root of
this repository:

```bash
createdb -h localhost -p 5432 -U dbowner brussels
# replace localhost with your database host, 5432 with your port,
# and dbowner with your database user
psql -h localhost -p 5432 -U dbowner -d brussels -c 'CREATE EXTENSION hstore'
# adds the hstore extension needed by osm2pgsql
psql -h localhost -p 5432 -U dbowner -d brussels -c 'CREATE EXTENSION MobilityDB CASCADE'
# adds the PostGIS and the MobilityDB extensions to the database
psql -h localhost -p 5432 -U dbowner -d brussels -c 'CREATE EXTENSION pgRouting'
# adds the pgRouting extension
```

Load the map and convert it into a routable network with the road types that
`BerlinMOD/mapconfig.xml` selects:

```bash
osm2pgrouting -h localhost -p 5432 -U dbowner -W passwd -f brussels.osm --dbname brussels \
  -c BerlinMOD/mapconfig.xml
```

## 2. Generating the data of Brussels

Load all the layers of the OSM file, including the administrative regions, and
prepare the home and work regions with the statistics of every municipality:

```bash
osm2pgsql -c -H localhost -P 5432 -U dbowner -W -d brussels brussels.osm
psql -h localhost -p 5432 -U dbowner -d brussels -f BerlinMOD/brussels/brussels_preparedata.sql
# samples home and work nodes, transforms the data to SRID 3857
```

Then run the generator of BerlinMOD at the scale factor wanted:

```bash
psql -h localhost -p 5432 -U dbowner -d brussels -f BerlinMOD/berlinmod_datagenerator.sql
psql -h localhost -p 5432 -U dbowner -d brussels \
  -c 'SELECT berlinmod_generate(scaleFactor := 0.005)'
```
